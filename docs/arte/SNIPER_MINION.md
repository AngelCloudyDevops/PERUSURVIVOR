# Minion francotirador

Atlas: `public/assets/minions/profession-sniper-integrated-v1.png` y recurso de ejecución WebP de 320 × 320. Creado con la herramienta integrada `image_gen` a partir del arquitecto para conservar la identidad del pingüino azul, el trazo cartoon, las nueve poses completas y la lectura a escala de juego.

Las dos primeras filas contienen seis pasos lentos. La última fila contiene preparación con rifle al hombro, disparo con retroceso y derrota sentada. El rifle es ficticio y forma parte de cada silueta; no se superponen accesorios de código. Los rangos veterano y élite reutilizan este atlas y se distinguen mediante el aro de rango ya existente para evitar tres descargas de textura casi idénticas.

Prompt y procedencia: `docs/arte/prompts/sniper-minion-prompts.json`. Hash, dimensiones y contrato alfa: `docs/arte/auditorias/minion-professions-audit.json`.
